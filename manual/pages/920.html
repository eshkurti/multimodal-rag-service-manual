Campaign - Install Navigation Road Map Database 2013

Audio, Navigation, Monitors, Alarms, SRS

Technical Service

PERFORM THE PROCEDURE OUTLINED IN THIS SERVICE INFORMATION ON ALL AFFECTED VEHICLES BEFORE CUSTOMER DELIVERY OR THE NEXT TIME THEY ARE IN THE SHOP FOR MAINTENANCE OR REPAIRS.

SITUATION
Before delivering affected vehicles to the customer, the Car Information Computer (CIC) road map database 2013 must be installed onto the CIC internal Hard Disc Drive (HDD).

AFFECTED VEHICLES
This Service Action involves E70, E71, E82, E84, E88, E89, E92, E93, F06, F12, F13, F25 and F30 vehicles which were produced from March 2012 to December 2012.

In order to determine whether a specific vehicle has had this Service Action completed or is affected by this Service Action, first check the B-pillar label for code number 628. If code number 628 has been punched out, the campaign has already been performed. If code number 628 has not been punched out, it will be necessary to utilize the "Service Menu" of DCSnet (Dealer Communication System) or the Key Reader. Based on the response of the system, either proceed with the corrective action or take no further action.

PROCEDURE

Step 1: Check the "in-service" date of the affected vehicle in the DCSnet Warranty Vehicle Inquiry.

^ If the vehicles in-service date is before November 1, 2012, no further action is required.

^ If on or after November 1, 2012, the vehicle is:

A "new vehicle in stock" (no in-service date in DCSnet); or

The vehicle has an in-service date in DCSnet on or after November 1, 2012. Perform Step 2.

Step 2: Check the installed road map database using the Key Reader.

A. If the Key Reader shows "Road Map North America Premium 2013," no further action is required.

B. [NEW] If the key reader shows "Road Map North America Premium 2012," refer to and perform the installation procedure as outlined in Attachment A.

[NEW] NOTE:
The INITIAL enabling code "FSC CIC map, N. America 2013 INITIAL" is necessary to start the installation process and to activate the road map database.

[NEW] IMPORTANT:
If the INITIAL enabling code "FSC CIC map, N. America 2012 INITIAL" was already ordered and downloaded in ASAP, or the CIC NAV road map database 2012 has already been activated in an affected vehicle:

^ [NEW] Use the REPAIR enabling code to install the CIC NAV road map 2013.

[NEW] In such a case it is no longer necessary to order the INITIAL enabling code "FSC CIC map, N. America 2013 INITIAL."

[NEW] For information on how to retrieve the REPAIR enabling code in ASAP, refer to Attachment B.








PARTS INFORMATION

LABEL INSTRUCTIONS

This Service Action has been assigned code number 628. After the vehicle has been checked and/or corrected, obtain a label (SD 92-417) and:

A. Emboss your BMW center warranty number in the middle of the label (1);

B. Punch out code number 628 (2), printed on the label; and





C. Affix the label to the B-pillar as shown.

If the vehicle already has a label from a previous Service Action/Recall Campaign, affix the new label next to the old one. Do not affix one label on top of another one, because a number from an underlying label could appear in the punched-out hole of the new label.
